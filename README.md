Built a simple SwiftUI Product List App to help beginners understand how to fetch and display API data using modern iOS development practices.

What this project covers:

✅ SwiftUI
✅ MVVM Architecture
✅ Async/Await (Swift Concurrency)
✅ API Calling with URLSession
✅ JSON Parsing using Codable
✅ Displaying data with List
✅ Search using .searchable()
✅ Loading state with ProgressView
✅ Dependency Injection using Protocols

This project is aimed at developers who are starting with SwiftUI and want to learn how to structure an app using MVVM while working with a real API.
